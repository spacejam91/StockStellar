{#- One value against the limit it has to clear. The scale is FIXED at `span` x the threshold, so the tick always sits at the same place and two rows can be compared by eye. It used to be max(floor, value * 1.15), which is the value's own scale -- so every bar above the floor rendered at exactly 100/1.15 = 87.0% wide regardless of the number beside it, and 83% of published bars were pixel-identical. A chart whose length does not vary with its data is worse than no chart: it looks like a measurement. A value past the end of the scale is clamped and marked, rather than silently rescaling everything around it. -#} {% macro meter(label, value, threshold, fmt, suffix, span=2.5) %} {%- if value is not none and threshold -%} {%- set v = (value | abs) -%} {%- set pct = 100 * v / (threshold * span) -%} {%- set over = pct > 100 -%} {%- set fired = v >= threshold -%}
{{ label }} {{ fmt | format(value) }}{{ suffix }}
{%- endif -%} {% endmacro %}
